# Trifour Tech Portfolio

This project is a small React portfolio site that showcases frontend, backend and data science work. The application is designed to run as a subdomain of **trifour.tech**.

## Features

- Built with React and React Router.
- Simple navigation with pages for Frontend, Backend and Data Science projects.
- Express server for serving the production build.

## Development

```
npm install
npm start
```

The development server runs on `localhost:3000` by default.

## Production

```
npm run build
npm run prod
```

The production build is served from the `dist` directory.
